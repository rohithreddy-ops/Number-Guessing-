# 🎯 Number Guessing Game Using Binary Search

A Python-based command-line game where the **computer guesses the number you are thinking of** using the **Binary Search algorithm**. Instead of the player guessing the number, the user provides hints, and the computer efficiently finds the correct answer in the fewest possible attempts.

## 🚀 Features

* Computer guesses the user's number.
* Uses the Binary Search algorithm for efficient searching.
* Custom start and end range.
* Interactive command-line interface.
* Input validation for invalid responses.
* Fast and optimized guessing process.

## 🛠️ Technologies Used

* Python 3
* Binary Search Algorithm

## 🎮 How to Play

1. Enter the starting and ending range.
2. Think of a number within that range.
3. The computer will guess your number.
4. Respond with:

   * **Y** if the guess is correct.
   * **N** if the guess is incorrect.
5. If incorrect, indicate whether your number is greater than the guessed number.
6. The computer continues until it correctly guesses your number.

## 💡 Algorithm Used

This project uses the **Binary Search** algorithm, which repeatedly divides the search range in half. This allows the computer to find the correct number in **O(log n)** time, making it much faster than checking every possible number one by one.
